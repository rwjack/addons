# Traefik SSL proxy

Home Assistant Supervisor add-on: TLS reverse proxy + ACME (DNS-01/rfc2136) +
TURNS-on-443 SNI passthrough to the **Coturn** add-on. Replaces the old `nginx` and
`core_letsencrypt` add-ons in this repository.

Add this repository in Supervisor → Add-on store → Repositories:

`https://github.com/rwjack/addons`
